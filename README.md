# Shift Sniper Pro — Website

## How to publish on GitHub Pages (FREE) in 5 minutes:

### Step 1 — Create GitHub account
- Go to github.com
- Sign up for free account
- Use any username (example: shiftsniperpro)

### Step 2 — Create new repository
- Click "+" → "New repository"
- Name it exactly: shiftsniperpro.github.io
  (replace "shiftsniperpro" with YOUR GitHub username)
- Set to Public
- Click "Create repository"

### Step 3 — Upload these files
- Click "uploading an existing file"
- Drag and drop ALL files from this folder:
  - index.html
  - privacy-policy.html
  - terms.html
- Click "Commit changes"

### Step 4 — Enable GitHub Pages
- Go to repository Settings
- Click "Pages" in left sidebar
- Under "Source" select "main" branch
- Click Save

### Step 5 — Your website is live!
- Wait 2-3 minutes
- Your website URL will be:
  https://YOUR-USERNAME.github.io

### Your URLs for Chrome Web Store:
- Homepage: https://YOUR-USERNAME.github.io
- Privacy Policy: https://YOUR-USERNAME.github.io/privacy-policy.html
- Terms: https://YOUR-USERNAME.github.io/terms.html
